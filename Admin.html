Manage your campus hub

Block-representative tool for updating the homepage, coursework, course resources, announcements, events, and Q&A. Changes publish to the shared site when the backend is available; otherwise they are saved in this browser.

Shared publishing: Start the site with npm start to save content on the server and share it with all students. For Google sign-in, add http://localhost:3000 and your deployed site origin to the OAuth client’s authorized JavaScript origins, then set $env:GOOGLE_CLIENT_ID="your-client-id"; npm start in PowerShell. If the backend is unavailable, content changes are saved in this browser only. The backend has no admin authentication; only expose it to trusted users.
